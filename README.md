# White Papers

Open white papers and executable engineering research by [Vijay Prakash Tiwari](https://github.com/vijayptiwari).

This repository is an index. Each paper remains in its own versioned repository so its history, issues, releases, citation metadata, implementation, and license remain independently usable.

## Published collection

### The 10 Pillars of Production Agent Engineering

A practitioner framework for designing, reviewing, and operating production agent systems, with a readiness rubric and design checklist.

- [Project repository](https://github.com/vijayptiwari/agent-engineering-framework)
- [Read the white paper](https://github.com/vijayptiwari/agent-engineering-framework/blob/main/whitepaper.md)
- [Version 1.2 release](https://github.com/vijayptiwari/agent-engineering-framework/releases/tag/v1.2)

### Evidence-Grounded Agent Routing

A decision-provenance framework for auditable, policy-aware, uncertainty-aware routing and delegation in LangGraph/LangChain-style agentic systems.

- [Project repository](https://github.com/vijayptiwari/evidence-grounded-agent-routing)
- [Read the white paper](https://github.com/vijayptiwari/evidence-grounded-agent-routing/blob/main/WHITEPAPER.md)
- [Version 0.1.0 release](https://github.com/vijayptiwari/evidence-grounded-agent-routing/releases/tag/v0.1.0)
- [Reference implementation](https://github.com/vijayptiwari/evidence-grounded-agent-routing/blob/main/IMPLEMENTATION.md)

## Publication principles

The collection favors implementable artifacts, explicit evidence boundaries, reproducible checks, visible negative results, and claims that match the maturity of the evidence. Synthetic development results are identified as such and are not presented as production validation.

## Citation

Cite the individual work rather than this index. Each project repository contains its own `CITATION.cff` file and preferred citation.
